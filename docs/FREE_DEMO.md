# FREE_DEMO — the "before they know it they're setup" funnel

## The insight

The demo IS the product. By the end of the 20-minute call, the workflow is
already working. The £20 is to keep it forever — not to start. This removes
the price objection from slide 1 entirely.

## The funnel

```
TikTok carousel (DM DEMO keyword)
  → DM arrives (manual or future automation)
  → Booking link sent (Calendly or similar)
  → 20-min demo call (we configure live, they watch)
  → Workflow working before call ends
  → "That's £20 to keep it forever. Want to add more?"
  → £20 payment → 7 days support → add-ons if they want them
```

## Why this works

1. **Zero friction on slide 1**: "Free demo" removes price from the decision.
   They're not buying anything — they're seeing something work.
2. **Demo = product**: By the time the call ends, the assistant is configured,
   the workflow is live, and they've seen it handle a real enquiry. The value
   is already delivered before any money changes hands.
3. **Loss aversion**: Once they've seen it work, losing it feels worse than
   paying £20 to keep it. The sunk cost is time (20 minutes), not money.
4. **Add-on upsell is natural**: "You've got bookings working. Want quotes
   too? That's £5." Each add-on is a small incremental purchase.

## Ad strategy

### 3 formats, 3 segments, 1 CTA

| Segment | Hook | Format | Why |
|---------|------|--------|-----|
| Electrician | "Free demo: quotes at 2pm, not 9pm — interested?" | Opportunity | Pain (9pm quotes) → solution (2pm) → free demo |
| Cleaners | "Free demo: paused plans restart themselves — agree?" | Before/After | Problem (chasing) → solution (automated restart) → free demo |
| Gardeners | "Free demo: rounds logged before you finish — sound good?" | Opportunity | Pain (paper rounds) → solution (auto-logging) → free demo |

### Posting cadence (week 1-2)

- **Day 1**: Electrician (highest-value segment, £499 standard offer)
- **Day 3**: Cleaners (volume segment, £20 wedge)
- **Day 5**: Gardeners (round workers, high pain)
- **Day 8**: Repeat top performer with different hook variant
- **Day 10**: Second-best segment, different format
- **Day 12**: Cross-segment winner (test if electrician hooks work for cleaners)

### Caption structure (200+ chars, SEO-optimised)

Every caption follows: hook + value promise + comment prompt + CTA + hashtags.

Example (electrician):
> Free demo: quotes at 2pm, not 9pm — interested? AI triages your enquiries,
> drafts quotes while you're on the tools, and follows up automatically. You
> approve every send. No subscription, no lock-in. Which would you automate
> first — quotes or follow-ups? DM DEMO for a free 20-min setup. #electrician
> #smallbusiness #ukbusiness #ai #automation #aiagent #workflow #timemanagement

### Sound selection

Match energy to format:
- Opportunity: mysterious/atmospheric (curiosity tone)
- Before/After: upbeat trending (transformation energy)
- Trust: ambient lo-fi (calm, reassuring)

## The trust model (why free works)

From `aionboard/TRUST_MODEL.md`:
- No passwords ever (customer logs in themselves)
- No money movement (quotes are drafts until approved)
- No silent sends (every message needs explicit approval)
- Revocable everything (one-click revoke)

This means the demo call is safe for the customer. We never touch their
accounts. We configure while they watch. They keep control the entire time.

## Post-demo flow

1. Customer DMs "DEMO" on TikTok
2. We reply with booking link (manual today, automated tomorrow)
3. 20-min call: we configure one workflow live on their device
4. Call ends: workflow is working, they've seen it handle a real case
5. We send summary email: what we set up, how to use it, what's next
6. "That's £20 to keep it forever. Want to add quotes/reminders/reviews?"
7. Payment → 7 days support → add-ons if they want them
